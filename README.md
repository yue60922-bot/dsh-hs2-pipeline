# 做衣服 mod

一套外来的衣服、头发或饰品模型，要变成 Honey Select 2 里能穿的 mod，通常卡在三处：按游戏的部位拆开，贴到男女身体或头模上，再打成衣橱里能搜到的 zipmod。这个插件把这三步放在一个流程图上。每步做完你看交付，点合格才往下。3D 文件交给 Codex 改。插件不读 DSH 的技能目录，规则在页面和提示词里。

管这些部位：上衣、下装、内衣、内裤、手套、裤袜、袜子、鞋、饰品、头发。衣身和裙摆连成一件的，整件留在上衣，不从腰撕开。饰品不贴合，做成 mod 时由 DSH 自己摆位置。头发只贴头模，打进游戏前缩小 100 倍。

它不进游戏替你试穿。没有预览图也不能点合格。绑骨、权重、ModdingTool 这些基础做法如果还没接触过，先看文末的 B 站参考，再回来跑流程。

## 要先有的环境

这是 DSH Web 的插件，不是单独一个程序。仓库放到 DSH 的 `local-plugins/dsh-hs2-pipeline`，在正在用的 profile 里启用它，再用你平时启动 DSH 的方式重启一次。侧边栏会出现「做衣服 mod」，和技能中心并列。

软件：

- DSH Web。
- Blender。用来改 `.blend`，也用来出预览图。
- 做到第 3 步才要：Unity **2018.4.11f1**、官方 ModdingTool 的 Unity 工程、Honey Select 2 游戏目录（里面有 `abdata` 和 `BepInEx`）。

模型文件，在页面的「环境设置」里填：

| 项 | 干什么 |
| --- | --- |
| 交付根目录 | `.blend`、预览图、zipmod 放这里。空着就用工作区里的 `hs2-pipeline` 文件夹 |
| 头模 | 头发只贴这个，不贴身体 |
| 女模 | 女装贴这个身体 |
| 男模 | 男装贴这个身体 |
| Blender 程序 | `blender.exe` |
| Unity 2018.4.11f1 | 只有第 3 步用 |
| ModdingTool 工程文件夹 | 只有第 3 步用 |
| 游戏目录 | 第 3 步装进游戏时用 |
| Codex 调用命令 | Codex 不在系统路径里才填。空着按普通的 `codex exec` |

路径改完，点「按当前环境重写全部提示词」。不点的话，已经生成过的提示词还是旧路径。

## Codex 和 CC Switch

只做饰品时不用装。饰品的拆分和摆放都是 DSH 自己做的，没有贴合，不开 Codex。

上衣、下装、内衣、内裤、手套、裤袜、袜子、鞋、头发，拆分、贴合、做成 mod 都要 Codex。项目里只要有这些部位，就要装。

用 CC Switch 配 Codex。最低配置：中转站 `nikoapi.xyz`，倍率 `0.21`，模型 `gpt-6-astra`。

DSH 里打开和当前 DSH 同一版本的官方 Codex 子代理插件 `dsh-subagent-codex`。旧的本地副本不要开。没开这个插件，上面那些部位派不出去。

## 页面上怎么走

侧边栏点「做衣服 mod」。从左往右是拆分、贴合、做成 mod，每个部位一条线。左边填项目名，素材可以是 zip、Blender 文件或文件夹。第一次拆分会立项，并建这个项目自己的文件夹。可以开多个项目页。

第一次点拆分、贴合、做成 mod，提示词发到新对话。发完留在这个页面。要改某一栏，就在那一栏写下改动，点「返工，只发这段」。返工留在当前对话，只发你新写的内容，并覆盖这一栏的预览图和 `.blend`。源贴图、UV、材质槽留着。

「删除这个项目」会连项目文件夹一起删。删之前会先问。

## 每一步交付看什么

预览图都是 Blender 里的多角度拼图：正面、侧面、背面、斜 45 度，一张里看全。必须是带原贴图的材质预览。只显示单色的 Solid 视图不算。点开图放大看，别只看缩略图。

### 拆分

真有的部位各交一个 `.blend` 和一张预览图。模型里没有的部位留空，不要为了凑格子硬切。

看这些：

- 连成一件的连衣裙整件在上衣里，裙摆没有被撕到下装。
- 脸、眼睛、指甲、皮肤没有交出来。材质名带 `+` 的背面层删掉了。
- 饰品一个个体一个文件。同一个饰品的 sp1、sp1.1 还在一起。页面上会自己多出 acc、acc2 这种分支。
- 打开 `.blend`，原来的 UV、材质槽、贴图节点还在，没有被换成单色。

有预览图才能点合格。

### 贴合

每个要贴的部位再交一个 `.blend` 和一张预览图。衣服的文件里带着女模或男模，头发的文件里带着头模。打开就能看到穿在身上，或套在头上。饰品没有这一步。

看这些：

- 衣服按它本来的穿法在身体上，没有拿另一件的角度硬套。
- 头发在头模上，没有按头骨名或挂点去对。缩放是 `0.01`。
- 衣服绑到这份身体骨架上，贴身的地方有权重。袖子没有绑到手掌和手指。裤袜的权重连到脚。鞋是脚先适应鞋，再绑骨、传权重。
- 头发绑在头模上，没有套身体那套 `o_body_cf_0` 权重。
- 贴图还是上一步那套。

有预览图才能点合格。

### 做成 mod

每件一个 zipmod，不要打成一个包。交付栏有游戏内搜索名，可以点「打开文件夹」。

看这些：

- 搜索名就是你在游戏里要搜的名字。饰品会带上它自己的名字。
- 文件夹里是这件的 zipmod。包根上是 `manifest.xml` 和 `abdata`。
- 头发打进去的是缩小之后的尺寸。默认进饰品·头部。要它出现在头发栏，做之前得说。
- 饰品挂在该挂的位置。腰上的不要到头上。
- 作者名是英文。中文作者名会让打包失败。
- 进游戏自己穿一次。交付里如果写了「未目视确认」，就是还没在游戏里看过。

## 卡住了

某一步对不上，或者你还不清楚绑骨、权重、ModdingTool 这些基础是怎么做的，去 B 站搜索「想做yk的狗」，用那个系列对一下。插件负责把流程和文件位置跑起来，基础制作逻辑以那个系列为准。
